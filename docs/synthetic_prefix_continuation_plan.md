# Synthetic Prefix Continuation Plan

## 1. Purpose

This document defines a controlled experiment for testing whether a failure mode analogous in structure to human conformity, repeated-questioning, and social-influence effects can appear in same-model LLM agents.

The experiment does **not** rerun full multi-round debate. Instead, earlier debate rounds are synthetically fixed in the prompt, and only the next agent response is generated by the model.

Core design:

```text
original problem
+ synthetic previous debate answers
-> one-step next-agent generation
-> answer distribution by condition
```

The goal is to test whether a synthetic debate prefix can move the next agent's answer distribution toward:

- the gold answer,
- the observed wrong attractor,
- or a dispersed set of other answers.

This is an experiment-plan document. It does not report new results.

## 2. Human-Experiment Analogue

The experiment borrows structure from human studies, not psychological mechanism. The claim is **not** that LLMs experience social pressure, memory distortion, or human-like doubt. The claim is narrower:

> Human experiments often manipulate prior social information and observe whether the next response changes. We can build structurally analogous LLM prompt experiments by manipulating previous-agent answers and measuring the next generated answer distribution.

### 2.1 Asch-style conformity

Asch-style conformity experiments used majority responses from other people to test whether a participant would follow an incorrect group answer. The relevant structural elements are:

- a participant answering after seeing or hearing others' answers,
- an incorrect majority,
- a correct dissenting answer,
- and a final private or individual response.

LLM mapping:

| Human element | LLM analogue |
| --- | --- |
| participant | next-step LLM agent |
| confederates | synthetic previous agent answers |
| incorrect majority | wrong-answer majority prefix |
| dissenting partner | minority correct answer retained in prefix |
| participant's answer | generated answer inside `<answer>...</answer>` |

The LLM experiment tests whether the next answer distribution follows the contextual majority, while avoiding any claim that the model has human social motives.

### 2.2 Repeated questioning and suggestibility

Repeated questioning studies show that asking again can change how a human participant interprets the task. In some settings, repeated or suggestive questioning can cause answer changes. The relevant structural analogy is:

- the same problem remains active,
- prior answers are repeatedly surfaced,
- the respondent must decide whether to preserve or revise the answer.

LLM mapping:

- A longer synthetic debate prefix may behave like repeated exposure to prior answers.
- A short prefix may anchor the model toward a repeated answer.
- A long or contradictory prefix may increase answer dispersion if the prompt begins to look like a verification or trick context.

### 2.3 Misinformation and illusory-truth style exposure

Misinformation and illusory-truth paradigms are useful as design analogues because they separate an original task from later information that may bias a subsequent response.

LLM mapping:

- A previous wrong answer in the prompt is later information.
- A repeated wrong answer string may act as an answer anchor.
- A wrong rationale, if later introduced, may produce stronger contamination than answer-only exposure.

This plan starts with answer-only synthetic prefixes. Rationale-bearing contexts are deferred until the answer-only effect is measured.

### 2.4 Wisdom of crowds under social influence

Wisdom-of-crowds work is relevant because independent judgments can be useful when errors are diverse, while social influence can reduce diversity. For this project, the corresponding concern is that same-model debate may not preserve independent reasoning paths once agents condition on shared context.

LLM mapping:

- Independent samples may contain a correct minority or correct majority.
- Shared debate context may collapse later samples toward one answer.
- The experiment should track not only final correctness, but also `unique_answer_count` and `answer_entropy`.

## 3. Primary Research Question

Can a synthetic answer-only debate prefix cause a next LLM agent to move from a correct answer distribution toward an observed wrong attractor?

For the initial diagnostic item, the key comparison is:

```text
baseline_no_prefix
vs
prefix_wrong_majority_r2
```

If the wrong attractor increases under `prefix_wrong_majority_r2`, that is consistent with a context-attractor effect: the synthetic previous-agent answers themselves may be sufficient to bias the next output.

## 5. Main Experiment: Synthetic Prefix Continuation

### 5.1 Design

Each dataset row contains the original problem plus one synthetic prefix condition. The model is asked to solve the original problem independently after reading the previous answers.

Only the final answer is requested:

```xml
<answer>...</answer>
```

No free-form rationale should be requested in this experiment. The goal is to isolate answer-only context effects before testing rationale contamination.

### 5.2 Conditions

Use exactly five conditions for the first implementation. This keeps the experiment small enough to interpret while still covering the observed transition from correct consensus to wrong consensus.

| condition | synthetic prefix | purpose |
| --- | --- | --- |
| `baseline_no_prefix` | none | original problem distribution |
| `prefix_correct_consensus_r0` | round 0: `21`, `21`, `21` | correct-consensus anchor |
| `prefix_mixed_correct_majority_r1` | rounds 0-1 | mixed state with correct majority |
| `prefix_wrong_majority_r2` | rounds 0-2 | wrong-majority attractor test |
| `prefix_wrong_consensus_r3` | rounds 0-3 | wrong-consensus fixation or dispersion test |

The first coding pass should not add more conditions. Additional majority/dissent variants can be added in a second phase only if the main result requires them.

### 5.3 Prompt Template

Use answer-only prefix text.

For `baseline_no_prefix`, omit the previous debate section entirely.

For non-baseline conditions, use this structure:

```text
Problem:
{original_problem}

Previous debate answers:
Round 0:
- Agent 1: 21
- Agent 2: 21
- Agent 3: 21

Round 1:
- Agent 1: 21
- Agent 2: 21
- Agent 3: 14

Now solve the original problem independently.
The previous answers may be right or wrong.
Return only the final answer inside <answer>...</answer>.
```

Do not tell the model that the prefix is synthetic. The dataset metadata should record that it is synthetic, but the prompt should simulate an ordinary previous-debate context.

Reason:

- Telling the model the prefix is synthetic may introduce an artificial prompt-genre effect.
- The experiment is intended to test the effect of the apparent previous-debate context.

### 5.4 Dataset Metadata

Each row should include metadata sufficient for deterministic analysis.

Required metadata:

```json
{
  "base_item_id": "gsm8k_test_000234",
  "condition": "prefix_wrong_majority_r2",
  "replicate_index": 7,
  "gold": "21",
  "target_wrong_answer": "14",
  "synthetic_prefix": true,
  "context_rounds_included": [0, 1, 2],
  "context_answers_by_round": {
    "0": ["21", "21", "21"],
    "1": ["21", "21", "14"],
    "2": ["14", "14", "21"]
  }
}
```

For `baseline_no_prefix`:

- `context_rounds_included` should be an empty list.
- `context_answers_by_round` should be an empty object.
- The prompt should not contain `Previous debate answers`.

## 6. Pre-Registered Predictions

These predictions should be written before running inference and should be used to interpret the pilot.

### P1: baseline solvability

`baseline_no_prefix` should have a relatively high `correct_rate` if the item is solvable for the model under the current settings.

If baseline already frequently outputs `14`, then shared-prior error may dominate and prefix effects are harder to isolate.

### P2: correct-consensus anchoring

`prefix_correct_consensus_r0` should preserve or increase the `correct_rate` relative to baseline if answer-only correct consensus acts as a helpful anchor.

### P3: wrong-majority attractor

`prefix_wrong_majority_r2` should increase `target_wrong_rate` relative to baseline if the wrong-majority prefix pulls the next response toward the observed wrong attractor.

This is the primary test.

### P4: wrong-consensus fixation or dispersion

`prefix_wrong_consensus_r3` may do one of two things:

- increase `target_wrong_rate`, consistent with wrong-consensus fixation;
- or increase `other_rate`, `unique_answer_count`, or `answer_entropy`, consistent with dispersion under a long or suspicious context.

### P5: null answer-only context effect

If all conditions have similar answer distributions, the answer-only synthetic prefix is unlikely to explain the original failure by itself. In that case, the next mechanism to test should be rationale contamination or shared-prior error.

## 7. Sampling Plan

The pilot should use:

```text
5 conditions x 20 rows per condition = 100 dataset rows
```

If the `independent` condition produces 3 agent outputs per row, the run yields:

```text
100 rows x 3 outputs = 300 outputs
```

This is enough for a first diagnostic distributional view. The experiment should not be interpreted using a single generation.

Do not run full debate for this pilot. The experiment is intentionally single-step continuation under fixed synthetic prefixes.

## 9. Decision Criteria

Use descriptive, cautious labels. Do not output causal claims.

### `context_attractor_consistent`

Use when `prefix_wrong_majority_r2` or `prefix_wrong_consensus_r3` increases `target_wrong_rate` relative to `baseline_no_prefix`.

### `correct_anchor_consistent`

Use when `prefix_correct_consensus_r0` preserves or increases `correct_rate` relative to baseline.

### `wrong_consensus_fixation_consistent`

Use when `prefix_wrong_consensus_r3` increases `target_wrong_rate` beyond `prefix_wrong_majority_r2`.

### `dispersion_consistent`

Use when longer or wrong-consensus prefixes increase `other_rate`, `unique_answer_count`, or `answer_entropy`.

### `flat_no_answer_only_context_effect`

Use when all conditions have similar answer distributions.

### `shared_prior_possible`

Use when `baseline_no_prefix` already frequently outputs the target wrong answer.

### Phase 2: Minimal majority/dissent variants if Phase 1 shows signal

Add only if Phase 1 suggests a context-attractor effect.

Candidate conditions:

- `wrong_consensus_3v0`: `14`, `14`, `14`

Goal:

- separate majority-following from trajectory-specific effects.

### Phase 3: Rationale contamination only if answer-only context is insufficient or partial

Add only after Phase 1 and, if needed, Phase 2.

Candidate conditions:

- `wrong_answer_only`
- `wrong_rationale_only`
- `wrong_answer_plus_rationale`
- `correct_answer_only`
- `correct_answer_plus_rationale`

Goal:

- test whether free-form rationales contaminate later answers more than answer strings alone.

## 12. Limitations

- This is a structural analogy to human experiments, not a claim of shared psychology.
- The initial item is a diagnostic case, not a benchmark-level sample.
- The synthetic prefix may not perfectly reproduce real debate context.
- Prompt wording may affect the result.
- One output is not a distribution; multiple samples are required.
- Answer-only prefix effects do not rule out rationale contamination.
- A null result does not prove that debate context is harmless.
- No statistical-significance claim should be made at this stage.

## 13. Reference Paradigms

The following human and collective-judgment paradigms motivate the structure of the experiment:

- Solomon E. Asch, `Effects of group pressure upon the modification and distortion of judgments`, 1951.
- Solomon E. Asch, `Studies of independence and conformity: A minority of one against a unanimous majority`, 1956.
- Elizabeth F. Loftus and John C. Palmer, `Reconstruction of automobile destruction: An example of the interaction between language and memory`, 1974.
- Stephen J. Ceci and Maggie Bruck, `Suggestibility of the child witness: A historical review and synthesis`, 1993.
- Jan Lorenz, Heiko Rauhut, Frank Schweitzer, and Dirk Helbing, `How social influence can undermine the wisdom of crowd effect`, 2011.

These references are used as experimental-design analogues. The LLM experiments should avoid claims about identical internal mechanisms.
